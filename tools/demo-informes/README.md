## Cómo importar

1. CARE 360 → **Fincas** → **Importar finca e informes**
2. Elige el Word Tucán o el CSV combinado
3. Revisa la vista previa (criterios · fotos · acciones) → **Importar**
4. Revisa **Visitas** (informe + fotos) y **Seguimiento** (plan de acción)
